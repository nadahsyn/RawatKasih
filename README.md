# RawatKasih

RawatKasih merupakan aplikasi mobile berbasis Jetpack Compose yang dirancang untuk membantu caregiver dalam memantau kondisi kesehatan lansia penderita hipertensi.

Aplikasi ini hadir sebagai solusi monitoring kesehatan jarak jauh dengan fitur pengingat obat, pencatatan kondisi harian pasien, serta monitoring aktivitas kesehatan secara sederhana dan terstruktur.

---

# Fitur Utama

## Caregiver Mode

| Fitur | Deskripsi |
|---|---|
| Kelola Data Pasien | Menambahkan dan mengatur data pasien lansia |
| Reminder Obat | Mengatur jadwal dan pengingat minum obat pasien |
| Monitoring Obat | Memantau status minum obat pasien |
| Monitoring Harian | Melihat kondisi kesehatan harian pasien |
| Riwayat Kesehatan | Melihat histori aktivitas dan kondisi kesehatan pasien |

---

## Patient Mode

| Fitur | Deskripsi |
|---|---|
| Reminder Minum Obat | Menampilkan jadwal minum obat harian |
| Konfirmasi Obat | Pasien dapat mengonfirmasi bahwa obat sudah diminum |
| Input Kondisi Harian | Mengisi kondisi kesehatan sederhana setiap hari |
| Jadwal Harian | Menampilkan aktivitas dan jadwal pasien |

---

## Fitur Umum

| Fitur | Deskripsi |
|---|---|
| Login & Register | Sistem autentikasi pengguna |
| Sinkronisasi Data | Data monitoring pasien tersimpan dan terhubung |

---

# Tujuan Aplikasi

* Membantu caregiver memantau kondisi lansia dari jarak jauh
* Meningkatkan kepatuhan pasien dalam minum obat
* Membantu pencatatan kondisi kesehatan harian secara lebih terstruktur
* Mengurangi risiko keterlambatan penanganan kondisi pasien
