# RawatKasih

RawatKasih merupakan aplikasi mobile berbasis Jetpack Compose yang dirancang untuk membantu caregiver dalam memantau kondisi kesehatan lansia penderita hipertensi.

Aplikasi ini hadir sebagai solusi monitoring kesehatan jarak jauh dengan fitur pengingat obat, pencatatan kondisi harian pasien, serta monitoring aktivitas kesehatan secara sederhana dan terstruktur.

---

# Fitur Utama

## Caregiver Mode

- Kelola data pasien
- Pengaturan jadwal dan reminder obat
- Monitoring status minum obat
- Monitoring kondisi harian pasien
- Riwayat aktivitas kesehatan pasien

## Patient Mode

- Reminder minum obat
- Konfirmasi “sudah minum obat”
- Input kondisi harian sederhana
- Tampilan jadwal harian pasien

## Fitur Umum

- Login & Register
- Pergantian role caregiver/pasien
- Sinkronisasi data monitoring pasien

---

# Tujuan Aplikasi

* Membantu caregiver memantau kondisi lansia dari jarak jauh
* Meningkatkan kepatuhan pasien dalam minum obat
* Membantu pencatatan kondisi kesehatan harian secara lebih terstruktur
* Mengurangi risiko keterlambatan penanganan kondisi pasien
